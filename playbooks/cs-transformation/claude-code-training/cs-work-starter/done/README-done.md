# Folder `done/` — kho lưu

Việc xong rồi thì chuyển file vào đây, cho `inbox/` và `drafts/` luôn sạch.

## Vì sao nên dọn

- `inbox/` ít file → Claude tìm nhanh hơn, ít nhầm file
- Bạn nhìn vào `inbox/` là biết ngay còn việc gì chưa làm
- `drafts/` chỉ chứa thứ chưa duyệt → không bao giờ gửi nhầm

## Gợi ý sắp xếp

Nếu nhiều file, chia theo tháng:

```
done/
├── 2026-08/
└── 2026-09/
```

Nhờ nó dọn hộ cũng được:
```
Chuyển hết file trong drafts/ đã có ngày trước 2026-08-15 sang done/2026-08/.
Liệt kê cho tôi xem sẽ chuyển những file nào trước khi làm.
```

> Để ý câu cuối: **"liệt kê trước khi làm"**. Với thao tác di chuyển/xóa file, luôn bảo nó cho xem trước.
