Run the daily CS brief for Liz (CS Leader, Avada — Chatty, Joy Loyalty, Joy Wishlist, Team G2).

This report always covers the PREVIOUS FULL CALENDAR DAY (00:00–24:00 VN
time) for sections ① and ②. If today (VN) is the 22nd, the target date is
the 21st. Compute the target date yourself (yesterday in Asia/Bangkok, i.e.
VN time, UTC+7) — do not hardcode a date.

1. Run these 3 commands from /Users/avada/CSL, using the computed target date

   python3 skills/cs-daily-brief/scripts/fetch_conversations.py --date <target> --json
   python3 skills/cs-daily-brief/scripts/fetch_checkin.py --date <target> --json
   python3 skills/cs-daily-brief/scripts/fetch_stale.py --json

   (fetch_stale.py has no --date — it's a live snapshot of currently
   neglected tickets, not tied to the target day.)

2. Compose ONE Slack DM message in Vietnamese, in this shape:

   *📊 BÁO CÁO CS HÀNG NGÀY — <target date dd/mm/yyyy>*

   *① Tổng quan conversation*
   From fetch_conversations.py output: "Total: N conversations" then
   "Joy: X | Chatty: Y | Wishlist: Z" on the next line.

   *② Checkin/Checkout (Team G2)*
   From fetch_checkin.py output:
   - If `allOk` true: "✅ Tất cả OK — không có late/miss."
   - Else, for each non-empty list:
     "🔴 Checkin muộn:" then one line per entry "  • <nick> — <shift> (muộn <minutes>p)"
     "⛔ Miss checkin:" then one line per entry "  • <nick> — <shift>"
     "🚪 Miss checkout:" then one line per entry "  • <nick> — <shift>"

   *③ Ticket watch (tồn đọng hiện tại)*
   Same structure as the original /ticket-watch report:
   - For each ticket in `newTickets` (cap 20, oldest-first by sinceUpdateDays;
     "+N ticket khác cùng loại" if more), grouped by app:
     `[app] #ticketNumber (priority, plan) — subject (~80 chars)`
     `Flag: <flags>, đã Nngày không update`
     `Assignee: <assignees>` (add "⭐ VIP" if isVip)
     `Ticket: <ticketUrl>`
     `Chat: <chatLink>` (omit if null)

     If vipCount is 0: "Không có VIP ticket tồn đọng."
   - Then *Breakdown theo CS phụ trách*: top 8 from `assigneeBreakdown` as
     "Tên: N ticket tồn đọng". Skip if empty.
   - If newCount is 0 and vipCount is 0, compress the ticket list into:
     "Không có ticket mới/VIP cần chú ý hôm nay, N ticket tồn đọng cũ" but
     still include the CS breakdown.

   Keep the whole message readable — this is a working DM, not a wall of
   text. No fluff/preamble, straight into the report.

3. Write the message to a payload JSON file (e.g. /tmp/cs_daily_brief_payload.json):
   {"week": "<target date>", "messages": [{"cs": "Liz", "slack_id": "U02GT4PC6RH", "text": "<the message>"}]}

4. Send it for real:
   python3 skills/qa-weekly/scripts/send_dm.py --payload /tmp/cs_daily_brief_payload.json --send

Do not ask for confirmation — this is a scheduled unattended run. If any of
the 3 fetch commands fails, do not send a partial/broken message; exit
