## 1. Getting Started

### Q1: How do I get started with Joy Wishlist?
**Frequency:** ~1 session
**Standard answer:** From the app Dashboard: (1) click **Enable**, then **Save** in the Theme Editor, then **Refresh** to confirm it's active; (2) customize how customers access the wishlist and how the Add-to-Wishlist button appears under **Wishlist Design**.
🔁 recurring (matches prior mine's Q1 onboarding topic)

### Q2: Where can customers find their wishlist?
**Frequency:** ~1 session
**Standard answer:** Customers can access their wishlist via a **header icon** (near cart/profile), a **floating button**, or a **"wishlist" link in the main menu** — whichever the store has enabled. To turn these on: **Apps → Joy Wishlist → Wishlist Design → Wishlist Access**, toggle on Header icon / Floating button / Main menu page as desired.
🔁 recurring

## 2. Wishlist Widget & Button Display

### Q3: Wishlist button not appearing on the product page / "Liquid templates don't support sections and blocks" error during setup
**Frequency:** ~2 sessions
**Standard answer:** On custom/non-standard themes where the product page is built as a single section, Shopify blocks inserting the app's button as a block via the dashboard setup — this triggers the "Liquid templates don't support sections and blocks" error. In this case, Joy Wishlist instead injects the button automatically via a script (below "Add to Cart"), independent of the block system. The fix: go to **Online Store → Customize → App embeds**, turn ON Joy Wishlist (and turn off any conflicting wishlist app), and disregard the dashboard error — the button will show correctly on the live storefront even though it won't appear inside the Theme Editor.
🔁 recurring (matches prior mine's Q8 button-not-showing topic)

### Q4: How do I turn on the wishlist button on collection page thumbnails?
**Frequency:** ~1 session
**Standard answer:** Go to **Wishlist Design → Wishlist Button**, turn on **"Show on collection page."** This requires a quick backend setup from the team (not fully self-serve) — share your store URL and preferred button position on the thumbnail, and the team will configure it and follow up.
🔁 recurring

### Q5: How do I move/reposition the wishlist heart icon on product cards or collection thumbnails (e.g. top-left → top-right)?
**Frequency:** ~2 sessions
**Standard answer:** There's no built-in position toggle for this — share the exact position you'd like (e.g. top right) and the team will apply it via custom CSS from the backend. No collaborator/store access is needed for a store-wide styling change like this.
🔁 recurring (same topic as prior mine's Q5)

### Q6: Can you change the wishlist icon's size, border, or background color (e.g. transparent background)?
**Frequency:** ~3 sessions
**Standard answer:** Basic icon/border/background color can be set under **Wishlist Design → Wishlist Access → General settings** (or **Wishlist Button → General settings** for the per-product heart icon) — these fields only support solid colors, so a fully transparent background isn't achievable directly from the settings (setting background to white with a colored icon can make it disappear against a white page). For icon resizing, border removal, or a genuinely transparent background, share the exact spec and the team will apply it via custom CSS from the backend — no collaborator code needed.
🔁 recurring — 🆕 new detail (background color field doesn't support transparent; noted in diff as PARTIAL)

### Q7: Can the wishlist button match the store's "Buy it now"/Add to Cart button style?
**Frequency:** ~1 session
**Standard answer:** There's no self-serve "Add Custom CSS" field for this in the app. Share what you'd like it to match (e.g. same shape/style as the Buy button) and the team will apply the styling from the backend.
🔁 recurring

### Q8: I switched the Wishlist Page display type (Full page ↔ Drawers) but nothing changed on the storefront
**Frequency:** ~1 session
**Standard answer:** The setting itself is applied immediately in the app — if the storefront doesn't reflect it, clear your browser cache or hard-refresh the page.
🆕 new (not previously documented as a KB troubleshooting tip)

## 4. Integrations

### Q10: Can wishlist price-drop alerts be sent through Klaviyo?
**Frequency:** ~1 session
**Standard answer:** Joy Wishlist doesn't have a direct/standalone Klaviyo connection — wishlist events only reach Klaviyo through an installed, Klaviyo-connected **Joy Loyalty** app. Price-drop notifications specifically aren't supported yet via any channel; this has been logged as a product request.
🔁 recurring

### Q11: Does the wishlist interact with the loyalty program (e.g. earn points for wishlist products)?
**Frequency:** ~1 session
**Standard answer:** Not directly today — Joy Wishlist and Joy Loyalty are separate apps with no product-level integration for points. If you're using the Unified Widget, customers can view their saved wishlist products inside the Joy Loyalty widget (hearts stay in sync), but there's no points-for-wishlist mechanic currently.
🔁 recurring

### Q12: Is there a migration path from another wishlist app (e.g. Swym) to Joy Wishlist?
**Frequency:** ~1 session
**Standard answer:** No import feature exists today from third-party wishlist apps. Logged as a product feature request.
🔁 recurring (matches prior mine's Q29 exactly, including the Swym example)

## 5. Analytics

### Q13: Can I see how many times a specific product was wishlisted?
**Frequency:** ~1 session
**Standard answer:** The Dashboard only shows store-wide totals (Total Items Added, Unique Customers, Conversion Rate) — there's no per-product wishlist count report today. The closest workaround is **Customers → Export CSV**, which lists each customer's wishlisted product titles, variants, prices, and add dates.
🔁 recurring
