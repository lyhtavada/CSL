## GAP detail (no verifiable official answer exists yet — see payload notes for which ones got patched)

**Q6 (freq 8) — draft-order Sales channel option missing from KB.** `kb__reference__points-advanced.md` "Sales channels" section only lists *Online store only / Online store & POS / POS only* for Place Order. The chat this week showed a working fix: changing the program's Sales channel setting to **"Online store and Admin draft orders"** so admin-created draft orders count too. This is a real, verifiable UI option (used successfully in the chat) — **patched** into `kb__reference__points-advanced.md`.

**Q21 (freq 8) — widget-not-showing checklist missing a real cause.** `kb__case__widget.md`'s "isn't showing at all" checklist (app embed / hide button / display-after-login / manual assignment) doesn't include the color-contrast cause found this week (Primary color set to white, blending into the page background, launcher physically present but invisible). **Patched** — added as a 5th check.

**Q39 (freq 4) — pixel disconnected fix missing the working workaround.** `kb__case__integrations.md`'s pixel section stops at "re-authorize → if that fails, escalate to recreate the pixel." This week an agent found a working fix in between: **toggle the Referral Program off then back on**, which forces Joy to re-register its Web Pixel (the pixel is tied to the referral feature). Given the KB itself already flags this pixel issue as rising toward the Aug 2026 migration deadline, this is a high-value, verifiable addition. **Patched.**

**Q53 (freq 3) — false "out of stock" on free-gift/perk products, root cause not documented anywhere.** Real, verifiable, recurring (3 independent sessions) cause: a linked product's **variant ID changes** after a Shopify-side product update, so the Joy program still references the old stale variant. Fix (used successfully in chat): remove the product from the program and re-add the current version. **Patched** into `kb__reference__redeeming-programs.md`.
