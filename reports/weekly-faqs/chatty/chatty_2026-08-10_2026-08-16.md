## 1. Getting Started / AI Agent Setup

### Q1: How do I set up the AI agent from scratch?
**Frequency:** ~65 sessions
**Status:** 🔁 recurring

**Standard answer:**
1. **AI agent → Training data → Manage** — add training data (Products, Collections, Discounts, Markets, FAQs, Custom knowledge). Products/Collections/Discounts sync automatically from the store; only Custom knowledge needs manual entry.
2. **AI agent → Instructions → Manage** — set tone/response behavior (custom instructions).
3. **AI agent → Settings** — set AI name, avatar, welcome message, availability.
4. **Test AI → Test now** — test before going live, then **AI agent → Turn on** to activate.

Chatty also offers a free "done-for-you" setup: the bot runs a guided intake (assistant name/greeting, 24/7 vs. business-hours only, notification channel/email, brand tone, off-limits topics, human-handover routing, order-lookup scope) and hands off to the CS team, who complete training and send a Loom/Jam walkthrough video for review — usually within a few hours to a day.

A faster self-serve path exists too: **AI agent → Suggested Q&A** proposes ~15 pre-drafted Q&As from store data for the merchant to accept/edit/skip.

### Q2: How do I enable the chat widget / live chat on my storefront?
**Frequency:** ~20 sessions
**Status:** 🔁 recurring

**Standard answer:**
1. Enable the app embed: **Online Store → Themes → Customize → App embeds** → toggle **Chatty** on → Save (legacy themes may show "Chatty - Core" or "Chatty - Core (legacy)" — enable the one matching the active theme).
2. In Chatty: **Chatbox → General** → turn on "Display chatbox on your store".
3. Under **Blocks**, turn on **Live chat**.
4. **Chatbox → Chat page → Pre-chat form** — choose whether to require guest info (email required, name/phone optional) or allow **Chat as anonymous**.
5. Reload the storefront to confirm the "Chat now" button appears.

### Q3: Can I add the Chatty widget to a non-Shopify website?
**Frequency:** ~2 sessions
**Status:** 🔁 recurring

**Standard answer:**
Yes. Go to **Settings → Integrations → Website integration**, copy the provided HTML or Liquid snippet, and paste it just before the closing `</body>` tag. It renders within a few minutes on any website, not only Shopify.

## 2. AI / Copilot Training

### Q4: Why did my AI give a wrong or fabricated answer (invented policy, wrong price, wrong product recommendation)?
**Frequency:** ~14 sessions
**Status:** 🔁 recurring

**Standard answer:**
When the AI has no matching FAQ/training-data entry, it can guess rather than say "I don't know" — this is a known limitation, not a setting you're missing. Fix: use **"Review Sources"** under the AI's test/live reply to see exactly which FAQ or data source it pulled from, then correct or add a Q&A at **AI agent → Training data → Manage → FAQs** (or **Custom knowledge**) with the accurate fact stated explicitly — e.g. "We do not offer financing or payment plans" rather than leaving the topic uncovered. For a wrong specific term/wording the AI keeps using, add an instruction under **AI agent → Instructions → Manage → General instructions → Behaviours**, e.g. "Always refer to X as Y." Re-test via **Test AI → Test now** after any change.

### Q5: The AI shared a discount/coupon code or made a product-recommendation claim I don't want it to make — how do I stop it?
**Frequency:** ~5 sessions
**Status:** 🆕 new

**Standard answer:**
- To stop unwanted product suggestions: **AI agent → Instructions → Manage → Assistant skills → Shopping skills → Product recommendations**, toggle off — or add a Behaviours instruction like "Do not recommend products unless explicitly asked."
- To stop the AI confirming/sharing discount codes: **AI agent → Instructions → Manage → Assistant skills → Custom scenarios → + Add scenario**, trigger on keywords (coupon/discount/promo code), with the instruction not to confirm or share codes. For a hard block, Training data's Discounts source itself can be disabled by support on request.

### Q6: My products / discounts aren't syncing into AI training data, or the AI says "no info" on catalog questions.
**Frequency:** ~8 sessions
**Status:** 🔁 recurring

**Standard answer:**
Confirm the relevant toggle is enabled under **AI agent → Training data → Manage** (Products / Discounts / Markets). Only **published, in-stock** products auto-sync, once daily on schedule — use the manual **Sync** button to force an immediate refresh. If a product genuinely won't sync, check it isn't restricted to a specific **Market** the AI wasn't tested against (market-specific catalogs can differ). If URL/file training data is stuck "In Progress" or "Failed", delete and re-add one at a time — a common cause is the source page being **password-protected**, which blocks the crawler (Shopify's own Shipping/Return/FAQ pages are exempt); the workaround is to paste the content into a supported file (PDF/CSV/TXT/JSON, 2MB max) and upload under **Custom knowledge → Add data → Files** instead.

### Q7: How do I get the AI to always reply in the customer's language (not English/store default)?
**Frequency:** ~6 sessions
**Status:** 🔁 recurring

**Standard answer:**
The AI already replies in whatever language the customer writes in, by default — this doesn't depend on the store's default language setting. If it's still answering in English, check: (1) an explicit instruction hasn't been added yet — add "Always respond in the same language the customer uses" under **AI agent → Instructions → Manage → General instructions → Behaviours"; (2) static/default content (Conversation Starters, the Human Handover message, FAQs shown as buttons) is translated separately at **Settings → Translation**, since only live AI replies auto-adapt — starter buttons and system messages need each language published there.

### Q8: How much can I put in AI Instructions, and can the character limit be raised?
**Frequency:** ~1 session
**Status:** 🔁 recurring

**Standard answer:**
Instructions has a ~1,000-character limit and support cannot raise it (risk of AI drifting/hallucinating with an overloaded prompt). For longer reference material, move it to **Training data → Custom knowledge**, which has a much higher limit.

## 3. Chatbox / Widget Setup & Display

### Q9: How do I reposition the chat bubble (it overlaps another button, or needs to move to a different corner)?
**Frequency:** ~7 sessions
**Status:** 🔁 recurring

**Standard answer:**
**Chatbox → Appearance → Chatbox button → Position** — pick an anchor corner or drag the position dot, then fine-tune with the Horizontal/Vertical offset sliders (0–45%). Precise pixel offsets or a mobile-only position (different from desktop) require **custom CSS**, which the team can apply on request — this isn't exposed as a self-serve setting.

### Q10: My proactive popup / promo banner keeps showing, or shows stale content (old discount code).
**Frequency:** ~3 sessions
**Status:** 🔁 recurring

**Standard answer:**
Each popup is its own **Proactive chat** campaign — open it and set Status to **Inactive** to stop it (this is separate from the Welcome Message, which only fires when the chat window itself is opened). Stale content usually means an old campaign's text/discount-code field was never updated — edit that specific campaign. Note: clearing the browser cache does **not** reset the "shown once per session" logic; the visitor needs a fresh tab/session to see it again.

### Q11: FAQ page or chatbox content isn't showing, or reverted to default/legacy content.
**Frequency:** ~6 sessions
**Status:** 🔁 recurring

**Standard answer:**
Most common root cause: the Chatty **app embed is off** in the theme (**Online Store → Themes → Customize → App embeds** → toggle Chatty on, Save) — content exists in the backend but nothing renders without it. If old default FAQ/Conversation Starter content is still showing after you edited it, check both places — **FAQs** (published Q&As) and the separate **Conversation Starters** list under **Chatbox → Chat page** — since Draft-status FAQs are correctly hidden but Conversation Starters is a different dataset entirely. Also check **Chatbox → General → Chat focus mode**: when on, it skips the Home screen (where the FAQ block lives) entirely, so FAQ status changes never get a chance to apply.

### Q12: Can I hide the chatbox on specific pages, or open it directly into chat/tracking via a link?
**Frequency:** ~2 sessions
**Status:** 🔁 recurring

**Standard answer:**
To hide on specific URLs: **Chatbox → Advanced → Display settings → Display pages → "Hide on specific pages"**, add the URL or a pattern like `/products/*`. To deep-link into a specific screen: append `#chatty-chat` (Live Chat), `#chatty-home`, `#chatty-tracking`, or `#chatty-help` to any store URL.

### Q13: The FAQ page font/styling doesn't match my theme, or a font-loading issue is flagged in a PageSpeed audit.
**Frequency:** ~2 sessions
**Status:** 🆕 new

**Standard answer:**
By default the FAQ widget can pick up its own font rather than inheriting the theme's — go to **FAQs → Appearance → Font** and switch to **"Default"** to inherit the theme font instead of an explicit Google Font (also avoids an extra font-loading request). If a PageSpeed/CLS report flags a Google Fonts request, verify the source before assuming it's Chatty — in a recent case the flagged request actually came from a different app's (Klaviyo) custom font `@import`, not Chatty, which loads its own fonts non-blocking via fonts.bunny.net.

## 4. Notifications

### Q14: I'm not getting notified when a new chat/message comes in.
**Frequency:** ~6 sessions
**Status:** 🔁 recurring

**Standard answer:**
Check **Settings → Notifications**: enable **Web push** (must click **Subscribe**, then also allow notifications for `app.chatty.net` in the browser's site settings) and/or **Email**. Make sure the triggers you need are on — "assigned to you," "unassigned conversation," "no reply for 15 minutes" are on by default, but "other members' conversations" and "AI-handled conversations" start off. Note notification triggers are set **per team member**, not inherited from an admin/global default — each person who should be alerted needs to enable it in their own account.

### Q15: Can AI take over automatically if a human doesn't reply within a certain time, even during business hours?
**Frequency:** ~1 session
**Status:** 🆕 new

**Standard answer:**
Not supported — there's no time-based failover. AI availability is schedule-based only: **"Always"** (AI on 24/7 regardless of team status) vs. **"Only when agent offline"** (AI only engages outside set business hours). A workaround for coverage gaps during working hours: set the online-status rule to "show offline when no agent is actually online, even within business hours" so the AI can still catch chats, or use the manual **Away Mode** toggle when stepping away (only available in the standalone web app at app.meetchatty.com, not inside the Shopify-embedded admin).

## 5. Team / Access

### Q16: How do I set what each team member can see or edit (granular permissions)?
**Frequency:** ~1 session
**Status:** 🆕 new (feature shipped)

**Standard answer:**
**Settings → Team → click a member → Permissions** — set each area (Chat availability, Reports, Channels & integrations, Billing & plan, etc.) to None/View/Edit individually per person.

### Q17: How do I change my login email, or activate my account for the first time?
**Frequency:** ~5 sessions
**Status:** 🔁 recurring

**Standard answer:**
First-time activation: open Chatty from **Shopify Admin → Apps**, look for the "Web app activation" banner (also under **Settings → Team** or **Chatbox → Live chat** block), click **Activate**, set a password (login email defaults to the Shopify account email), then log in at app.chatty.net. To change the login email afterward: on Free plan this **replaces** the current email (only one allowed); support processes the change and sends a verification code to the new address to confirm.

## 6. Integrations

### 6a. WhatsApp / Messenger / Instagram

### Q18: How do I connect WhatsApp, and why doesn't my existing number show up?
**Frequency:** ~4 sessions
**Status:** 🔁 recurring

**Standard answer:**
Requires a Meta Business Manager account with Admin role and a WhatsApp Business number not already tied to the regular WhatsApp/Business **app** (only Cloud-API-eligible numbers work). Connect via **Settings → Channels → WhatsApp**. If your number doesn't appear because it's still linked to the mobile Business App, it must first be migrated: back up chat history, delete the mobile app account (not just uninstall), create a WABA in Meta Business Suite, re-verify the number by OTP, and enable 2-step verification on it — then it becomes connectable (and stops working in the personal WhatsApp app once linked). All WhatsApp messages then route only into **Chatty Inbox → WhatsApp tab**, not the personal app.

### Q19: Can't send/receive images or files over WhatsApp/Messenger.
**Frequency:** ~1 session
**Status:** 🔁 recurring

**Standard answer:**
Two distinct causes seen: (1) Meta blocks any third-party app from sending files once **24 hours** have passed since the conversation started — a Meta platform policy, not a Chatty bug. (2) Within the 24h window, file delivery can fail due to a backend upload issue (fixed when reported). Attachment support also varies by channel — Messenger only accepts images/PDF/Word (Meta limitation); spreadsheets aren't supported on any channel.

### 6b. Email

### Q20: How do I set up email forwarding into the Chatty Inbox, and why is it stuck "unverified"?
**Frequency:** ~4 sessions
**Status:** 🔁 recurring

**Standard answer:**
Chatty gives a unique forwarding address; add a forwarding rule in your provider (e.g. Gmail: **Settings → Forwarding and POP/IMAP** → set the rule to forward-and-keep-a-copy) pointing to it, send a test email, then reload Email settings — status should flip to verified. Only one email can be bound per store via forwarding (use alias forwarding for a second address). Known limitation: **Outlook/Hotmail-domain** forwarding has a confirmed incompatibility with Chatty's mail platform causing bounce errors from `mailer-daemon@amazonses.com` — not fixable short-term; workaround is relaying through an intermediate Gmail inbox, or migrating to Google Workspace/Zoho Mail.

### Q21: Can I change the "From" name/address on outbound emails, or the "Reply-To"?
**Frequency:** ~2 sessions
**Status:** 🔁 recurring

**Standard answer:**
"From" name/domain is changeable at **Channels → Sender Email** (edit the Name field, or verify a custom sending domain). "Reply-To" is fixed to Chatty's internal routing address by design, so customer replies route back into the Inbox — this cannot currently be changed.

### 6c. Order tracking & API

### Q22: How does order tracking work, and can I use a custom tracking link?
**Frequency:** ~3 sessions
**Status:** 🔁 recurring

**Standard answer:**
Default provider is 17TRACK (no setup needed, works with most carriers). Configure at **Settings → Integrations → Order tracking**: default carrier tracking, a **Custom tracking link** (any plan, including Free), or your own **17TRACK** account/Security Key. The AI's live order-lookup (customer asks "where's my order" in chat) requires matching an order ID with the email/phone on file, and needs **Basic plan or higher**.

### Q23: Does Chatty have a public API? Can I pull conversation data into my own CRM?
**Frequency:** ~2 sessions
**Status:** 🆕 new detail (correction)

**Standard answer:**
Yes, on **Pro and Plus plans** — generate a key at **Settings → API**. The same key works for `GET /chat/conversations` (list, paginated via `nextCursor`, filterable by status/channel/email) and `GET /chat/conversations/{id}/messages`. No separate "beta" enrollment is required beyond having an active key on a qualifying plan — correcting an earlier support answer that said beta access needed a special grant. Role-restricted/scoped API keys aren't supported yet (feature request).

## 7. FAQ Management & Data Export

### Q24: Can I bulk-import or bulk-export FAQs/conversations?
**Frequency:** ~5 sessions
**Status:** 🔁 recurring

**Standard answer:**
**FAQs**: bulk import/export is self-serve via **FAQs → More actions → Import/Export FAQs** (CSV with Question/Answer/Category/Published/Featured columns) — but this only covers general FAQs, not product-specific ones (those are added per-product, no bulk tool yet — logged as feature request).
**Conversations**: single-conversation export is self-serve (open a conversation → ⋮ menu → **Export transcript**). Bulk export by date range is **not self-serve** — send the team a date range + account email and they export/email a CSV, usually within minutes. Exportable fields: conversation ID, country, language, channel, page chat started on, message timestamps, sender type, order ID/amount/payment method (if linked). **Not** tracked/exportable: UTM source/medium/campaign, device/browser/OS, payment or refund/dispute status (those live in Shopify).

### Q25: A specific FAQ throws a 404 when I try to edit it, even though others work fine.
**Frequency:** ~1 session
**Status:** 🆕 new

**Standard answer:**
This has been traced in at least one case to a corrupted record ID on a small number of imported (spreadsheet-uploaded) FAQs — don't delete and recreate them, since that removes the evidence needed to fix the underlying record; report the exact question(s) affected so the team can investigate directly. As a workaround, editing via the **category tabs + Ctrl+F** on the main FAQ list (instead of the search bar) has not reproduced the error.

## 8. Translation

### Q26: How many languages can my chatbox support, and how many are auto-translated?
**Frequency:** ~7 sessions
**Status:** 🔁 recurring

**Standard answer:**
Add the language in **Shopify Admin → Settings → Languages** first, then **Settings → Translation → Add language** in Chatty. Click **Auto-translate** (or edit manually), **Save**, then the settings icon → **Publish → Confirm** — saving alone doesn't push it live. For the AI's own replies, it already auto-detects and replies in the customer's language regardless of chatbox UI language.

|---|---|---|
| Free | 1 | 0 — manual only |
| Basic | 3 | 2 |

## 10. Edge Cases / Bugs / Feature Requests

### Q30: Can Chatty block spam or repeat-abuse messages hitting the chatbot?
**Frequency:** ~1 session
**Status:** 🔁 recurring

**Standard answer:**
No native IP-level blocking, bot-detection, or CAPTCHA — blocking inside Chatty is session-based only and doesn't stop a new session from the same visitor. Mitigations: require the pre-chat form (name/email) to add friction, set a spending cap on AI usage, or turn on **Settings → Automation → Spam protection → Smart spam protection**, which auto-classifies and blocks spam/abusive messages without requiring the pre-chat form.

### Q31: Can I tag conversations by topic, and can tags be auto-assigned by keyword?
**Frequency:** ~1 session
**Status:** 🔁 recurring

**Standard answer:**
Manual tags are supported (open a conversation → tag panel) and can be filtered on. Automatic tag assignment by keyword is **not** currently available — every tag is added manually per conversation (logged as a feature request).

### Q32: Can I see what language a customer's message is in before replying, or use a fully custom/AI-agnostic build (custom auth, live video, third-party API calls)?
**Frequency:** ~2 sessions
**Status:** 🔁 recurring / 🆕 new (feasibility scoping case)

**Standard answer:**
There's no indicator of a customer's source language in the Inbox before replying — logged as a feature request. Separately, on custom-build feasibility: Chatty's AI can be trained on product/FAQ/custom content, do guided product recommendations, run scenario-based flows, and hand off to a human — but it cannot call third-party APIs at runtime, generate documents, host live video sessions, or handle account-level auth flows (OTP/login) inside the chat. For a request needing any of those, be upfront that it's out of scope rather than promising a workaround.

## 11. Notable Bugs Found & Fixed This Week (for awareness, not active issues)
